# 星火 · 1927—1949（第一部）

一部纯前端的中文历史文字冒险 × 视觉小说。**二十二年，二十九段，四条完整长线。**

一九二七年秋天，你被一根绳子捆进军营；一九四九年十月一日，你在一个县城的操场上听见那句“今天，成立了”。

这二十二年，你要走井冈山、古田、长征、太行、山东、大别山、淮海、渡江。
第五段和第八段各做一次决定，从此走上四条不同的路：一一五师、一二九师（归队）、一二九师（审查未结）、新四军。
二十九段，一段一图，一段一决。

> **谨以此作，献礼中国工农红军长征胜利九十周年 · 1936—2026。**

## 这部作品在思想政治教育里做什么

它不是把结论念一遍，而是把结论还原成一个人要面对的具体处境。

- **让信仰有重量。** 长征、肃反、皖南、反“清乡”——每一次选择都没有标准答案，但都有代价。
  玩家在屏幕上犹豫的那几秒，就是“信仰”这两个字最接近可感的时候。
- **让代价看得见。** 每一次选择后面都跟着伤亡、失散、审查、饥饿；没有“无损通关”。
  学生记住的不是“苦”，而是“为什么还是往前走”。
- **让人民具体。** 半袋小米的老太太、推独轮车的民工、抬担架的沂蒙妇女、送盐的老表——
  群众路线不是概念，是一个个愿意把最后一口吃的给你的人。
- **让历史有坐标。** 平型关、阳明堡、关家垴、黄桥、皖南、孟良崮、淮海、渡江，
  每一段都对应真实的时间、地点、番号与军区；一一五师在山东、一二九师在太行，出关与大别山各走各的，错了就是错了。
- **让选择有后果。** 没有“无损通关”：你争来的主攻，班里可能少两个人；你救下的伤员，可能拖慢整个连。
  二十二年走下来，玩家记住的不是数值，是那几次犹豫。

作为思政教学的辅助材料，它可以配合课堂使用：课上讲结论，课后走一遍路。

## 结构

**29 段**：第一段—第十五段（1927—1937），第十六段—第二十九段（1937—1949）。

**两条路线**在第五段 E-3 定下：

- **主力线**：第六段 → 第八段 → 第十段 / 第十一段 / 第十二段（三选一）→ 第十四段 → 第十六段起
- **留守线**：第七段 → 第九段 → 第十三段 → 第十五段 → 第二十四段起

**三条主力支线**在第八段 H-3 定下，分别接抗战时期的：

| 支线 | 1937 年编入 | 抗战—解放战争 |
|---|---|---|
| J | 一一五师 | 平型关 → 山东 → 出关 → 辽沈 → 平津 → 南下湘西 |
| K | 一二九师（归队） | 阳明堡 → 太行 → 大别山 → 淮海 → 渡江 → 鄂西 |
| L | 一二九师（审查未结） | 七亘村 → 太行 → 大别山 → 淮海（位置靠后）→ 后方 |

留守线编入新四军：韦岗 → 黄桥 → 皖南 → 反“清乡” → 孟良崮 → 淮海 → 上海。

**四个结算层**：`J_END` / `K_END` / `L_END` / `G_END`，各带 12 行时间轴、4 件纪念物、4 个按钮。
